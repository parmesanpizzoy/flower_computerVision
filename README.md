🖼️ Image Processing & Computer Vision Fundamentals (Python & OpenCV)

This repository contains a collection of hands-on code and basic experiments in image processing using Python, OpenCV, NumPy, and Matplotlib. The project covers the fundamentals of digital image manipulation, from loading images and histogram equalization to thresholding techniques and various filtering and blurring methods.

🚀 Key Features & Modules

The main script covers 5 essential stages of image processing:

Python & NumPy Basic Review: An introduction to core Python data structures (list, tuple) and array manipulation with NumPy.
Load & Display Image: Loading images from your device (Google Colab supported) and displaying them with Matplotlib in RGB format.
Histogram Equalization: Converting images to grayscale, counting pixel frequencies manually, and equalizing the histogram to improve image contrast.
Thresholding Techniques: Applying binary segmentation techniques, including:
Binary Thresholding
Inverse Binary Thresholding
Otsu’s Thresholding (automatic)
Image Filtering & Blurring: Applying filters to smooth images or reduce noise, including:
Averaging Blur
Gaussian Blur
Median Blur
Bilateral Filter
🛠️ Prerequisites

Make sure you have installed the following Python libraries before running the program:

pip install opencv-python numpy matplotlib
